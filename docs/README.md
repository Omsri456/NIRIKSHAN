# MPLADS Risk Intelligence Platform

SIH PS-102 — AI-powered monitoring and analytics for MPLADS.

## Project Purpose
Identify MPLADS works requiring attention by combining data analytics, anomaly detection, NLP similarity, compliance rules and explainable risk scoring.

## Stack
- React + TypeScript
- Node.js + Express + TypeScript
- MongoDB
- Python ML service
